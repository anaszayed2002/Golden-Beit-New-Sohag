# Golden Beit New Sohag

منصة جولدن بيت لعرض وطلب أراضي مجاورات وأحياء سوهاج الجديدة (مميز ومتوسط).

- الموقع: https://sohag.goldenbeit.com
- Next.js 15 (App Router) على Vercel، مشروع `golden-beit-new-sohag`، أي push على `main` بيتنشر لوحده
- Supabase project `golden-beit-new-sohag` (`lbbayvojqvaziproordg`)

## الصفحات

| المسار | الوظيفة |
| --- | --- |
| `/` | البحث: الفئة، المنطقة، المجاورة، الميزانية، فلاتر من/لحد، ترتيب تصاعدي وتنازلي، 24 أرض في المرة |
| `/land/[code]` | بطاقة الأرض، «اسأل على واتساب» بالكود، طلب شراء بالاسم والرقم، المقارنة |
| `/compare` | مقارنة لحد 3 أراضي |
| `/sell` | «اعرض أرضك» على 5 خطوات (آخرها مراجعة)، الاسم والرقم إجباري، من غير حساب |
| `/admin` | لوحة التحكم: بحث بكود الوحدة، مراجعة، الأراضي، طلبات الشراء، التنبيهات، نسخ البطاقة، حذف |

مفيش حسابات للعملاء. حساب الأدمن الوحيد بالرقم الموجود في جدول `admin_phones`، والتسجيل مقفول.

## قاعدة البيانات (`supabase/migrations`)

- `lands`: بيانات الأرض العامة. الكود بياخد أصغر رقم فاضي من GB-1001 (`next_land_code`).
- `land_private`: اسم البائع ورقمه ورقم القطعة (الأدمن بس).
- `purchase_requests`، `land_alerts`: طلبات الشراء والتنبيهات.
- `submit_land(p jsonb)`: إرسال إعلان من غير حساب، 10 في اليوم لكل رقم.
- حدود يومية: طلب شراء واحد لكل رقم على نفس الأرض و10 في اليوم، 3 تنبيهات في اليوم.

## التشغيل محليًا

```bash
cp .env.example .env.local   # وحط NEXT_PUBLIC_SUPABASE_ANON_KEY
npm install
npm run dev
```

`mockups/` فيها ماكيتات التصميم بس، ومش جزء من الموقع.
